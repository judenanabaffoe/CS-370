## Course Overview

This repository contains coursework, lab assignments, and project artifacts completed for **CS 370: Current and Emerging Trends in Computer Science** at Southern New Hampshire University. 

The course explores modern computational paradigms, artificial intelligence systems, reinforcement learning architectures, and ethical frameworks governing emerging technologies. Core focus areas include designing intelligent agents, understanding neural network primitives, training autonomous models within simulated environments, and analyzing computing trends shaping the industry.

---

## Key Learning Objectives

* **Intelligent Systems Design:** Implement fundamental Artificial Intelligence (AI) and Machine Learning (ML) algorithms to solve decision-making problems.
* **Reinforcement Learning:** Formulate Markov Decision Processes (MDPs), design reward functions, and train agents using Q-learning and Deep Q-Networks (DQN).
* **Heuristics & Search:** Apply informed and uninformed search strategies, pathfinding techniques, and optimization heuristics.
* **Ethical & Societal Implications:** Evaluate algorithmic bias, autonomous safety protocols, data governance, and ethical responsibilities in real-world deployment.
